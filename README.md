# 🚀 Typing Speed Tester

A simple and interactive Typing Speed Tester built using **HTML, CSS, and JavaScript**.  
This project calculates typing speed (WPM) and accuracy after a 60-second timer.

---

## 📌 Features

- ⏱️ 60-second countdown timer  
- ▶️ Start button  
- ⏸️ Pause button  
- 🔄 Reset button  
- 📊 Automatic popup showing:
  - Words Per Minute (WPM)
  - Accuracy (%)
- 🌙 Neon Dark Theme UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Neon Dark Theme)
- JavaScript (Vanilla JS)
